# Orbit-specific calibrated interaction clock

This is supplemental exploratory material for the 5x5 seed-75202 orbit.

The decoder is calibrated on the complete 1,941-state macro-orbit under
`G = F^5`. It can recover phase exactly on that calibrated orbit, but it is
best understood as a compact encoded atlas. It is **not** a universal HPP
interaction law and the core exact claims do not depend on it.
