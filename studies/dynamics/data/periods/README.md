# Period-navigation data

Core CSV files are generated deterministically with:

```bash
python scripts/generate_periods.py
```

The directory contains the complete 3x3 six-collision-count certificate,
exhaustive 3x3 and 4x4 period summaries, the 4x4 density-horizon and
interaction-fiber summaries, the exact 5x5 seed-75202 2,209-state fiber
decomposition, phase/sensor summaries, a finite-field linear-invariant
certificate, and a fixed 500-state empirical 5x5 period sample.
