# Cosmic Coordinate

Coordinate grammar:

`M / Phi_C`

Current declared reference coordinate:

`M3 / Phi_C=0.7376`

Files:

- `spec.md` — definitions and equations
- `timeline.csv` — reference epoch and phase milestones
- `clock.py` — working coordinate calculator

`Phi_C` is a matter/dark-energy composition coordinate. It is not a recurrence phase or recurrence-cycle phase.
