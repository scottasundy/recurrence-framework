# Contributing

Contributions should preserve the repository's evidence boundaries.

1. Do not promote a sampled or model-conditional result to an exact or observationally established claim.
2. Every recurrence claim must specify the state/observable being compared, the metric where applicable, and whether the return is exact or approximate.
3. New cosmological probability weights must state the model set, priors, likelihood/data combination, and which portions are data-informed versus theory-supplied.
4. Do not use Recurrence Dynamics toy-model results as evidence that the physical universe is finite or recurrent.
5. Do not call `Phi_C` a recurrence phase.
6. Add or update tests for numerical changes.
7. Run `python scripts/verify.py` before submitting a change.
8. If time-sensitive public cosmology inputs change, update provenance, source-verification notes, and affected outputs together.
